# ChuchiEng

Trang chủ website học tiếng Anh ChuchiEng.

## Cấu trúc thư mục

```
chuchieng-web/
├── index.html        # Trang chủ
├── css/
│   └── style.css     # Toàn bộ style
├── js/
│   └── script.js      # Logic lịch học (calendar)
├── images/
│   ├── logo.png       # Logo ChuchiEng
│   └── bear.jpg        # Ảnh gấu góc học tập
└── README.md
```

## Chạy thử trên máy

Mở trực tiếp file `index.html` bằng trình duyệt, hoặc dùng Live Server (VS Code extension) để có auto-reload khi chỉnh sửa.

## Triển khai bằng GitHub Pages

1. Push repo này lên GitHub.
2. Vào **Settings → Pages**, chọn nhánh `main` và thư mục `/ (root)`.
3. Sau vài phút, trang sẽ có sẵn tại `https://<tên-tài-khoản>.github.io/<tên-repo>`.
